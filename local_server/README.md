# ShelterED - Локальний сервер укриття

Цей сервер дозволяє проводити перекличку та навчання в укритті навіть без доступу до інтернету.

## Як запустити сервер (для вчителя):

1. **Увімкніть Wi-Fi точку доступу:**
   - Натисніть на іконку Wi-Fi у правому нижньому куті екрана Windows.
   - Перейдіть у налаштування "Мобільна точка доступу" (Mobile Hotspot).
   - Увімкніть її. (Назва мережі та пароль мають бути налаштовані заздалегідь).

2. **Запустіть сервер:**
   - Відкрийте папку з програмою (папка `ShelterED_Server`).
   - **Двічі клікніть на файл `ShelterED_Server.exe`**.
   - (З'явиться чорне вікно терміналу — це нормально, не закривайте його, поки триває урок!).

3. **Як учням підключитися:**
   - Учні підключаються до вашої Wi-Fi мережі.
   - Відкривають браузер (Chrome, Safari) і вводять адресу: `192.168.137.1:8000` (або сканують QR-код з екрана вчителя).

## Як користуватися:
- **Для учня:** Сторінка `http://192.168.137.1:8000/` — тут велика кнопка "Я в укритті".
- **Для вчителя:** Сторінка `http://192.168.137.1:8000/teacher` — тут таблиця зі статусами учнів та QR-код для швидкого підключення.

## Як це працює (для розробників):
- **Backend:** Python, FastAPI.
- **База даних:** SQLite (`shelter.db` створюється автоматично).
- **Синхронізація:** Фоновий скрипт `sync_worker.py` відправляє накопичені дані в хмару (через API ), коли з'являється інтернет.
- **Збірка:** PyInstaller для створення `.exe` файлу (команда: `pyinstaller --noconfirm --onedir --name="ShelterED_Server" --add-data "templates;templates" run.py`).
