# ShelterED - Локальний сервер укриття

Цей сервер дозволяє проводити перекличку та навчання в укритті навіть без доступу до інтернету.

## Як запустити сервер (для вчителя):

1. **Увімкніть Wi-Fi точку доступу:**
   - Натисніть на іконку Wi-Fi у правому нижньому куті екрана Windows.
   - Перейдіть у налаштування "Мобільна точка доступу" (Mobile Hotspot).
   - Увімкніть її. (Назва мережі та пароль мають бути налаштовані заздалегідь).

2. **Запустіть сервер:**
   - Відкрийте папку `local_server`.
   - Двічі клікніть на файл `run.py` (або запустіть його через термінал командою `python run.py`).

3. **Як учням підключитися:**
   - Учні підключаються до вашої Wi-Fi мережі.
   - Відкривають браузер (Chrome, Safari) і вводять адресу: `192.168.137.1:8000` (або ту IP-адресу, яку видає ваш ноутбук).

## Як користуватися:

- **Для учня:** Сторінка `http://192.168.137.1:8000/` — тут велика кнопка "Я в укритті".
- **Для вчителя:** Сторінка `http://192.168.137.1:8000/teacher` — тут таблиця зі статусами учнів.

## Як це працює (для розробників):
- **Backend:** Python, FastAPI.
- **База даних:** SQLite (`shelter.db` створюється автоматично).
- **Синхронізація:** Коли з'являється інтернет, сервер має відправляти накопичені дані в хмару (в розробці).
